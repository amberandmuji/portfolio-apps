# Twenty Years in the Windy City · 風城二十年

A desktop browser walk-through of twenty years in Hsinchu, Taiwan, in four chapters:
Qianjia Station (childhood), Hsinchu Girls' High (high school), NYCU (university)
and Big City (now). Each chapter ends with a first-person cutscene.

- **Play:** open `index.html` in a desktop browser (a single self-contained file; three.js loads from jsDelivr). Works as-is on GitHub Pages.
- **Demo:** `demo.mp4`, a 15-second 1080p trailer rendered from the real scenes.
- **Source:** `source/` (Vite + three.js). `cd source && npm install && npm run dev`.

Controls: WASD to walk, mouse to look, Shift to run, E to interact, Space to skip a cutscene.
