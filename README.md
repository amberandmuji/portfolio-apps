# portfolio-apps

Small interactive projects, each in its own folder with a playable build, a README and its source.

| App | What it is |
| --- | --- |
| [hsinchu-wind](hsinchu-wind/) | **Twenty Years in the Windy City · 風城二十年**: a desktop browser walk-through of twenty years in Hsinchu, Taiwan, in four chapters. [Demo video](hsinchu-wind/demo.mp4) |
| [starside-campfire](starside-campfire/) | **Starside Campfire**: a browser music toy where you wake, rest and invite travelers around a night-forest campfire to build a slow, spacey band. [Demo video](starside-campfire/demo.mp4) |
