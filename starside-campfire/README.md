# Starside Campfire

A browser music toy set at a campfire in a night forest. Six travelers sit around the fire, each playing an instrument: nylon guitar, frame drum, wooden flute, squeezebox, washtub bass and kalimba. Tap a traveler to wake or rest them. Seven more players (theremin, cello, music box, humming, singing bowl, pocket synth, seed shaker) wait to be invited. Every part is generated live with the Web Audio API in D major at 68 bpm, so any combination stays in tune and in time.

Inspired by one of my favorite games of 2026.

- **Play:** open `index.html` in a browser. It's a single self-contained file (fonts load from Google Fonts) and works as-is on GitHub Pages. Press "Sit by the fire" to start the sound.
- **Demo:** `demo.mp4`, a 10-second 4:3 (1440×1080) clip recorded from the real scene, with the game's own music as the soundtrack.
- **Share a mix:** each lineup has a code like `mix-111111-2200000`. Add `#` and the code to the end of the page link, or paste the code into "Load mix".
